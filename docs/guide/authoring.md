# Authoring with Carve 0.2

The Laravel facade renders and validates Carve 0.2 source. HTML import remains available through the Carve2 importer. Markdown input import is waiting for a 0.2 engine API and reports an unavailable error.

Use the [migration guide](migration-02.md) to update existing source and settings. It links the 0.2 upgrade tool and explains SILENT source changes.
