# Carve 0.2 syntax

The [Carve 0.2 specification](https://github.com/markup-carve/carve/tree/main/spec/0.2) is the source of truth for syntax. Run the 0.2 upgrade tool before using existing 0.1 documents. The [upgrade guide](https://github.com/markup-carve/carve/blob/main/spec/0.2/UPGRADING.md) identifies silent HTML changes.
