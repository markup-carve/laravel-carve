# Installation

Require the package with Composer. PHP 8.2 and the DOM extension are required. The service provider and facade are discovered by Laravel.

```sh
composer require markup-carve/laravel-carve:^0.2
```

Carve 0.1 users stay on the 0.1 series and its [documentation](https://markup-carve.github.io/laravel-carve/0.1/).

See the [migration guide](migration.md) for the current API and options.
